# 🍴 Restaurant App Project

مشروع متكامل لإدارة مطعم إلكتروني تم بناؤه باستخدام إطار العمل **Flask** وقاعدة بيانات **SQLite**. يتيح النظام للمستخدمين طلب الطعام أونلاين، ويوفر لوحة تحكم كاملة للمسؤول (Admin) لمتابعة الطلبات.

---

## ✨ المميزات الرئيسية (Features)

### 👤 للمستخدمين (User Side):
* **نظام حسابات كامل**: تسجيل حساب جديد وتسجيل الدخول وحماية الجلسة (Session).
* **تصفح المنيو**: عرض الأصناف المتاحة مع الأسعار والصور من قاعدة البيانات.
* **عربة التسوق (Cart)**: إضافة الأصناف وحذفها وحساب الإجمالي تلقائياً.
* **نظام الطلب (Checkout)**: إتمام الطلب وحفظه في النظام بحالة "Pending".

### 🛠 للمسؤول (Admin Side):
* **لوحة التحكم**: عرض الطلبات، حساب الإيرادات، وإدارة قائمة الطعام.
* **إدارة الأصناف**: إضافة أصناف جديدة مع رفع الصور، تعديل الأسعار، أو حذفها نهائياً.
* **تحديث حالة الطلب**: تحويل حالة الطلبات المكتملة إلى "Done".

---

## 🚀 التقنيات المستخدمة (Tech Stack)

* **اللغة**: Python 🐍.
* **إطار العمل**: Flask (التعامل مع المسارات والجلسات).
* **قاعدة البيانات**: SQLite3 (تخزين بيانات المستخدمين، الأصناف، والطلبات).
* **Frontend**: HTML templates مع Jinja2 لعرض البيانات الديناميكية.

---

## 📂 هيكل قاعدة البيانات (Database Schema)

يحتوي المشروع على الجداول التالية:
1. **users**: لتخزين بيانات الاعتماد (id, name, username, password).
2. **menu**: لتخزين أصناف الطعام (id, name, price, image).
3. **orders**: لتخزين تفاصيل الطلبات وحالاتها (id, items, total, status).

---

⚙️ طريقة التشغيل (Setup)
لضمان تشغيل مشروع المطعم بشكل صحيح على جهازك، اتبعي الخطوات التالية:
تثبيت المكتبات اللازمة:
تأكدي من تثبيت إطار العمل Flask وجميع المتطلبات اللازمة من خلال الأمر التالي في الـ Terminal:
pip install -r requirements.txt

تهيئة قاعدة البيانات:
عند تشغيل التطبيق لأول مرة، سيقوم الكود تلقائياً بإنشاء ملف database.db وإنشاء جداول المستخدمين والمنيو والطلبات بفضل دالة init_db().
بدء تشغيل السيرفر المحلي:
قومي بتشغيل ملف التطبيق الأساسي لبدء العمل:
python app.py
بعد التشغيل، يمكنكِ الوصول للموقع عبر الرابط المحلي الافتراضي: http://127.0.0.1:5000.
بيانات الدخول للوحة تحكم المسؤول (Admin):
للتحكم في الطلبات وإضافة وجبات جديدة، توجهي إلى المسار /admin_login واستخدمي البيانات التالية:
كلمة المرور الافتراضية: admin123
### لوحة تحكم المسؤول (Admin Dashboard)
توضح الصورة التالية إجمالي الإيرادات، قائمة الطلبات الحالية، وإمكانية إضافة أصناف جديدة للمنيو.
