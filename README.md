# Restaurant App Project

## Technical Documentation
In this project, we handle the database using **Python** and **SQLite**. 

### Key Concepts:
1. **Connection**: We use `sqlite3.connect` to open the connection with the database file.
2. **Cursor**: We use the `cursor` to execute SQL commands (like fetching menu items or adding orders).
3. **Commits**: We use `connection.commit()` to save any changes made to the database.
